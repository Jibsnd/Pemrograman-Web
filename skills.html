Kemampuan (Skills)

Keahlianku terbagi menjadi dua dunia yang sering bersinggungan: pemrograman teknis dan produksi kreatif.

Technical & Programming

  • C++ & Game Engine: Penguasaan sintaks, manipulasi piksel 2D, dan perancangan mekanik game menggunakan framework SFML.
  • Python & Pengolahan Data: Eksekusi data preprocessing, penanganan missing value, serta plotting visualisasi data menggunakan library Pandas dan Seaborn.
  • Hardware: Pemahaman analitis mengenai struktur embedded system, integrasi VLSI, dan pemahaman arsitektur komponen.

Audio & Creative Production

  • Audio Engineering: Multitrack recording, routing audio interface, dan eksekusi stem export workflows menggunakan FL Studio.
  • Sound Design: Eksplorasi karakter amplifier, perakitan sirkuit efek (overdrive/fuzz), dan manajemen setup pedalboard.
  • Fotografi & Visual: Penguasaan kontrol manual kamera dan teknik fotografi low-light (menggunakan Canon EOS M50 Mark II), serta manipulasi prompt untuk aset grafis.
